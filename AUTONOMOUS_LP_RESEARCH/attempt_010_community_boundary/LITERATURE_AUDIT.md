# Attempt 010 — Literature audit

Working name: Multi-Scale Community Boundary Profile (MSCBP)

The pair object combines same-community status, within/outside neighborhood mass, normalized community boundary ratios, community-size contrast, and the number of communities touched by the two endpoint neighborhoods.

Novelty collision is `L1`: community-aware link prediction and flow/community similarity are established. It is retained only as a cheap probe to test whether a pair-conditioned boundary profile adds anything beyond the locked controls.

Sources checked: [Community-enhanced Link Prediction in Dynamic Networks](https://doi.org/10.1145/3580513), [Similarity-based Link Prediction from Modular Compression of Network Flows (LoG 2022)](https://proceedings.mlr.press/v198/blocker22a/blocker22a.pdf), and [Hierarchical Supergraph Neural Networks for Link Prediction (2026)](https://www.nature.com/articles/s41598-026-62637-6).
