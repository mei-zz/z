# Novelty risks

Performance is not novelty. The GRAPH block is classical projected common-neighbor count plus degree normalization. R retains its frozen CONTEXT_DRIVEN interpretation; size causality remains NOT_SUPPORTED. Deep Sets already establishes invariant set aggregation; NCN/NCNC already learns common-neighbor candidate structures. The raw-star hypergraph is computed from the original graph, so this sprint cannot establish extra native hypergraph information beyond that graph. The mathematical counterexample concerns a lossy unweighted projection; it is not a priority claim or a weighted-projection separation. The earlier focused novelty audit remains scoped and incomplete. This sprint performs no new exhaustive literature-priority audit.

Primary references: [Deep Sets](https://arxiv.org/abs/1703.06114), [Neural Common Neighbor with Completion](https://arxiv.org/abs/2302.00890). Canonical validation has influenced numerous previous candidate choices. A new inner TRAIN holdout, when the preregistered gate permits it, reduces but does not erase this risk. No test scores are generated. Citeseer is a fixed validation-only stress test and cannot be used for architecture selection.
