# Best Supported Candidate

## Result

**None.** No new architecture reached the implementation gate.

The strongest supported research object is a problem statement, not a model:

> On fixed hard-negative link-prediction candidates, Parent has a repeatable low-MRR subgroup, but existing AA/RA and feature-based proxies already explain a substantial part of the ranking signal. A valid new model must improve beyond these controls under a predeclared distribution-shift protocol.

This is a useful starting point for a later study, but it is not an independent network innovation and is not a paper-ready contribution.

## Why a candidate was not selected

- A hard-negative local reranker repeats the failed pair-decoder pattern and collides with SEAL/NCN/NCNC/MPLP-style methods.
- An uncertainty/topology denoiser collides with PULL/CORE/LEAP and lacks a runnable public protocol in the current remote workspace.
- An inductive topology module lacks a valid node-disjoint benchmark in the current workspace.

No code, parameter count, or performance claim is attached to these rejected ideas.
