## Closest primary works

| Work | What it establishes | Relationship to ECPH |
|---|---|---|
| Yoon et al., *Persona2vec: A Flexible Multi-role Representations Learning Framework for Graphs* (2021) | The paper's refined ego-splitting describes removing the ego, identifying local clusters, and creating a persona for each cluster. It explicitly names each connected component of the ego-network as the simplest local-community partition. [Primary article](https://pmc.ncbi.nlm.nih.gov/articles/PMC8022511/), [author PDF](https://www.yongyeol.com/papers/yoon2021persona2vec.pdf) | **Strong conceptual overlap:** ego-minus-ego connected components already represent local groups. Persona2vec splits node representations and rewires a persona graph; it does not preserve one original star while adding `{ego} ∪ component` hyperedges for pairwise link prediction. The component primitive itself cannot be claimed as new. |
| Pan et al., *Unsupervised Attributed Network Embedding via Cross Fusion* (WSDM 2021) | Its cross-fusion layer builds an ego-network, partitions the neighbors into connected components, then aggregates within each group. [Author-hosted paper PDF](https://cs.nju.edu.cn/yuanyao/static/wsdm2021.pdf), [publication record](https://experts.illinois.edu/en/publications/unsupervised-attributed-network-embedding-via-cross-fusion/) | **Strong conceptual overlap:** component-based ego-neighbor grouping and aggregation are established. The paper builds node representations, not a graph-induced hypergraph with a retained raw star plus component hyperedges. |
| Eldaghar, Zhu & Gleich, *A Spatial Hypergraph Model to Smoothly Interpolate between Pairwise Graphs and Hypergraphs to Study Higher-Order Structures* (PLOS Complex Systems, 2025) | For every point, cluster its neighbor set and create one hyperedge per cluster together with the original point. The paper explicitly describes this center-plus-neighbor-cluster construction. [Primary article](https://doi.org/10.1371/journal.pcsy.0000066), [author PDF](https://www.cs.purdue.edu/homes/dgleich/publications/Eldaghar%202025%20-%20spatial%20hypergraph.pdf) | **Direct structural precedent:** this is the same center-plus-neighbor-cluster hyperedge template as ECPH. Its clusters come from DBSCAN on spatial nearest neighbors, not connected components of a graph-induced neighbor subgraph; its goal is studying higher-order structure, not pairwise link prediction; and it does not specify retaining the original closed-neighborhood star as an additional edge. The broad construction template is therefore not new. |

## Search conclusion

**Candidate A status: `NOVELTY_CONFLICT` for the broad construction template; exact link-prediction augmentation remains unverified.** The 2025 spatial hypergraph paper explicitly creates center-plus-neighbor-cluster hyperedges, while persona2vec and Cross Fusion establish connected-component ego partitioning. ECPH's graph-induced connected-component rule, Raw-star retention, and fixed-operator pairwise link-prediction evaluation form a narrower combination not verified by these papers, but only that combination could be considered for further academic study. Candidate A is empirically rejected, so it should not be advanced as the paper's core innovation.

## Candidate B — ECNH

| Work | What it establishes | Relationship to ECNH |
|---|---|---|
| Jo et al., *Edge Representation Learning with Hypergraphs* (NeurIPS 2021) | Dual Hypergraph Transformation maps graph edges to nodes of a hypergraph and applies hypergraph message passing to edge representations. [NeurIPS primary record and abstract](https://proceedings.neurips.cc/paper/2021/hash/3def184ad8f4755ff269862ea77393dd-Abstract.html), [paper PDF](https://papers.nips.cc/paper_files/paper/2021/file/3def184ad8f4755ff269862ea77393dd-Paper.pdf) | Establishes broad edge-centric hypergraph representation learning. It uses a dual transformation for graph representation/generation/classification, not a hyperedge `{u,v} ∪ CN(u,v)` added to a node-centered graph hypergraph for pairwise LP. |
| Lu et al., *Neighborhood Overlap-aware Heterogeneous Hypergraph Neural Network for Link Prediction* (Pattern Recognition, 2023) | Uses overlapped-neighborhood structure in a heterogeneous hypergraph/link-prediction model. [Primary publisher record](https://www.sciencedirect.com/science/article/pii/S0031320323005162) | Confirms overlap-aware hypergraph LP is established. It does not match the specific per-observed-edge common-neighbor hyperedge construction in this sprint. |
| Huang et al., *Importance-guided Neighborhood Aggregation for Link Prediction via Adaptive Link Representation* (Knowledge-Based Systems, 2026) | Treats candidate links as link-centric representations and explicitly models common-neighbor-related joint structural dependencies. [Primary publisher record](https://www.sciencedirect.com/science/article/abs/pii/S095070512600818X) | Strong task-family overlap for edge/link-centric common-neighbor representations, but it describes adaptive feature aggregation rather than the ECNH hyperedge list. |

**Candidate B status: `CONCEPTUAL_OVERLAP; EXACT_CONSTRUCTION_UNVERIFIED`.** Edge-centric hypergraph representations and common-neighbor-aware link prediction both have established precedents. The focused search did not identify the exact augmentation rule `{u,v} ∪ CN(u,v)` over each target-masked observed edge, capped at 16 common neighbors, while retaining Raw stars and holding the incidence operator fixed. This is not a novelty guarantee; the construction should be framed as a narrow empirical hypothesis, not a new general edge-centric or common-neighbor idea.

## Candidate C — OWH

| Work | What it establishes | Relationship to OWH |

| Chai et al., *Hypergraph Modeling and Hypergraph Multi-view Attention Neural Network for Link Prediction* (Pattern Recognition, 2024) | Proposes graph-to-hypergraph modeling for ordinary graph link prediction and a hypergraph motif representation that distinguishes open and closed hypermotif structures. [Primary publisher record](https://www.sciencedirect.com/science/article/pii/S0031320324000438), [HMRLH article](https://www.mdpi.com/2079-9292/12/23/4842) | **Direct novelty conflict:** open/closed motif-derived hypergraph structures have already been used for link prediction. | Rossi et al., *Higher-Order Ranking and Link Prediction: From Closing Triangles to Closing Higher-Order Motifs* (2019) | Defines motif closure for link ranking/prediction, generalizing the open-wedge-to-triangle transition beyond triangles. [Primary preprint](https://arxiv.org/abs/1906.05059) | Open wedges as link-formation structures and motif closure for LP are established; OWH cannot claim triadic-closure link prediction as new. |
| Veldt et al., *Correlation Clustering via Strong Triadic Closure Labeling* (ICML 2022) | Defines an open-wedge hypergraph whose vertices represent graph edges and whose 3-hyperedges encode wedges for a weighted vertex-cover objective. [Primary PMLR paper](https://proceedings.mlr.press/v162/veldt22a/veldt22a.pdf) | Further evidence that “open-wedge hypergraph” is already a named construction family. It is not the same node-triple hyperedge used by OWH here. |

**Candidate C status: `NOVELTY_CONFLICT` for generic open-wedge/motif hypergraph link prediction; exact Raw augmentation unverified.** C is retained only as the final mechanism experiment under the user's registered candidate order. It must not be positioned as a paper-core novelty. Generic motif-driven construction is an explicit conflict; the narrow triple augmentation is an empirical question.
